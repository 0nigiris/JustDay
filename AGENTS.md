# JustDay — правила работы

Этот файл читают обе оболочки: Claude Code (через `CLAUDE.md`, он ссылкой сюда) и OpenCode
(`AGENTS.md` он берёт сам). Правила одни и те же, в какой бы из них ни шла работа, — иначе смена
модели посреди дела означала бы ещё и смену привычек.

## Что это

Личный ассистент для Linux (KDE Plasma 6, Wayland): демон на Python и оболочка на QML/Quickshell —
Dynamic Island, док, лоток, меню, Spotlight. Голос, окна, музыка, почта, видео. Мозг — Claude Code
через Agent SDK; при лимите спускается по лестнице поставщиков.

- `src/justday/` — демон, инструменты, CLI (`justday …`).
- `island/` — всё, что видно на экране.
- `shell/opencode/` — лестница нейросетей для оболочки OpenCode.
- `docs/ПЛАН.md` — что делаем и в каком порядке. Это очередь, а не список пожеланий.

## Общие правила

Поверх этого файла действуют `docs/ПРАВИЛА.md` — они общие для всех сессий и всех оболочек:
работать до конца, вести `ПЕРЕДАЧА.md`, пользоваться инструментами, и список того, что проверяется
перед выпуском наружу. Если что-то противоречит — верх берут общие правила.

## Язык

Всё по-русски: ответы человеку, комментарии в коде, сообщения коммитов, тексты на экране.
Английский остаётся там, где он и был: имена переменных, API, названия инструментов.

## Комментарии

Комментарий объясняет **почему**, а не что. «Увеличиваем счётчик» писать не надо — это видно.
Надо писать то, чего в коде не видно: какая беда была, какой случай сломался, почему выбран этот
путь, а не очевидный. Хороший комментарий переживает переписывание функции.

## Проверки перед коммитом

```sh
ruff check .
.venv/bin/python -m pytest -q
/usr/lib64/qt6/bin/qmllint -I . island/ИМЯ.qml      # для изменённых QML
bash -n install.sh                                  # если трогали установщик
```

Тесты пишутся на то, что **сломалось у человека**, а не на то, что легко проверить. В названии и
в docstring — беда, а не механика: «одна настройка ломала весь конфиг», а не «проверка set_value».

## Выкладка

```sh
git push origin main
git -C ~/.local/share/justday/app pull -q --ff-only
systemctl --user restart justday justday-ui
```

Ветка `main` защищена правилом: чужой push требует одобрения, владелец проходит.

## Чего делать нельзя

- Ключи, пароли и токены — только в связке ключей рабочего стола (`secret-tool`). Не в конфиге,
  не в исходниках, не в памяти ассистента. В оболочку они попадают переменными окружения.
- Управляющий сокет и любой наш порт наружу не смотрят: только 127.0.0.1.
- Необратимое (удаление, оплата, отправка) спрашивает подтверждение. Запуск программы — не
  спрашивает: подтверждение на каждый пуск это не безопасность, а шум.
- Сервер minevpsex и плату ESP32 не трогать.
- Отключать защиту ради простоты установки нельзя.

## Как выглядит сделанная работа

Коммит объясняет причину, а не перечисляет файлы. Сообщение пишется так, чтобы через полгода было
понятно, какую беду оно чинило. Хвост у коммитов — соавторство и ссылка на сессию.
