# Шип: сколько на самом деле стоит оболочка

Это не начало переписи на Rust. Это измерительный прибор, собранный ради **одного числа** —
чтобы разговор «Quickshell жирный, перепиши на Rust» вёлся по измерению, а не по ощущению.

```bash
cargo build --release && ./target/release/barspike      # полоса появится у верхнего края
```

## Что меряли

`barspike` — полоса layer-shell у верхнего края экрана: цветной кружок и несколько белых
прямоугольников вместо текста, нарисованные на процессоре в разделяемую память. Ни шрифтов, ни
значков, ни видеокарты.

## Что намерили (2 октября 2026, Fedora 44, KDE Plasma 6 Wayland, NVIDIA)

| | Rust-полоса | Вся наша оболочка |
|---|---|---|
| RSS | 3,7 МБ | 307 МБ |
| **PSS** (честная доля, без двойного счёта разделяемого) | **1,3 МБ** | **147 МБ** |
| потоков | 1 | 12 |
| CPU в покое | 0% | 0% |

Из чего состоят наши 147 МБ:

| | |
|---|---|
| куча и аноним (объекты QML, JS, растры значков, наши данные) | 79 МБ, 54% |
| прочие системные библиотеки | 35 МБ, 24% |
| видеодрайвер и GL | 14 МБ, 10% |
| **библиотеки Qt и QML** | **10 МБ, 7%** |
| сам quickshell | 4 МБ, 2% |
| шрифты | 2 МБ, 1% |

## Что из этого следует

**Qt — не причина.** Его библиотеки занимают 10 мегабайт из 147. Половину съедает куча: объекты
QML, движок JavaScript, растры значков. Переписав на Rust, мы избавились бы от движка JS и от
накладных расходов на объекты QML — но не от растров, не от состояния шести окон, не от
видеодрайвера.

**Честная оценка выигрыша — 90–120 МБ** из 147, если переписать всё с теми же возможностями: шесть
окон, лоток по SNI, PipeWire, MPRIS, сервер уведомлений, меню, размытия. Это месяцы работы.

**По процессору выигрыша нет вовсе: в покое у обоих ноль.** Тридцать процентов ядра, которые
действительно жглись, оказались ошибкой в одной строке QML — крутилка, анимировавшаяся в скрытом
виде. На Rust эта ошибка стоила бы ровно столько же.

**Поэтому решение: не переписываем.** Но шип остаётся в репозитории: если однажды понадобится
полоса, которая обязана занимать три мегабайта и запускаться мгновенно, она начнётся отсюда.
