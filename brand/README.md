# Фирменный знак JustDay

Монограмма JD с синей точкой над J (выбрана 24 нояб.). Все файлы собирает `scripts/brand.py`
из одной геометрии; править нужно там, а потом запускать `python3 scripts/brand.py`. Надписи
переведены в кривые, поэтому Inter на чужой машине не нужен.

| файл | где применять |
|---|---|
| `justday-mark.svg` | знак светлыми линиями, для тёмного фона |
| `justday-mark-flat.svg` | знак тёмными линиями, для светлого фона |
| `justday-mono.svg` | один цвет, красится через `currentColor` |
| `justday-lockup-dark.svg` | знак и слово на тёмной подложке |
| `justday-lockup-light.svg` | знак и слово без подложки, для светлого фона |
| `justday-lockup-ru.svg` | то же со словом «Джарвис» |
| `justday-icon.svg` | значок приложения, 1024×1024 |
| `justday-favicon.svg` | мелкий значок: поля меньше, иначе на 16 px буквы не различить |
| `justday.ico` | значок exe под Windows: 16, 32, 48 и 256 px |

Цвета: `#0A0A0D`, `#F5F5F7` и акцент `#0060DF`. Акцент тот же, что синий по умолчанию в
островке (`JD.accents.blue`): белый текст на нём даёт около 5,6:1.

Правило одно: **одно яркое пятно на весь знак**, это точка. Второй акцент её убьёт.
