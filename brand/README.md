# Фирменный знак JustDay

Описание и все размеры — `docs/логотип.json`. Здесь готовые файлы; надписи переведены в кривые,
поэтому Inter на чужой машине не нужен.

| файл | где применять |
|---|---|
| `justday-mark.svg` | знак сам по себе, со свечением |
| `justday-mark-flat.svg` | то же без фильтра — туда, где свечение съедают (печать, мелкий размер) |
| `justday-mono.svg` | один цвет: зрачок и чёрточка вырезаны. Красится через `currentColor` |
| `justday-lockup-dark.svg` | знак + слово на тёмном |
| `justday-lockup-light.svg` | знак + слово на светлом |
| `justday-lockup-ru.svg` | то же со словом «Джарвис» |
| `justday-icon.svg` | значок приложения, 1024×1024 |
| `justday-favicon.svg` | 16 px: только капсула и зрачок, чёрточку убрали — на такой величине она сливается |

Геометрия считается от высоты капсулы `H`: ширина `2.4·H`, зрачок `0.34·H` со смещением влево на
18 % ширины, чёрточка длиной `1.6` и высотой `0.34` диаметра зрачка. Цвета только из палитры:
`#0A0A0D`, `#0A84FF`, `#64D2FF`, `#F5F5F7`.

Правило одно: **одно яркое пятно на весь знак**. Второй акцент его убивает.

Файлы собраны скриптом из геометрии, а не нарисованы мышью, — если понадобится другая пропорция,
проще пересчитать, чем править путь руками.
