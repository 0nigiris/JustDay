## «How Award-Winning Websites Are Really Built» (@aiwithcasti, 12 стр.)
Стек сайтов-«победителей»: GSAP+ScrollTrigger, Lenis (плавный скролл), Three.js, Spline, Theatre.js,
Framer/Webflow. Приёмы: 3D из **последовательности картинок** (60–150 кадров WebP на canvas,
кадр по положению скролла — 60 fps на любом телефоне); pin/scrub/stagger; прелоадер ≤2,5 с;
**один акцентный цвет, одна кривая, 3 длительности** (fast .3/base .6/slow 1.1); проверки перед
выпуском: Lighthouse на телефоне, LCP < 2,5 с, CLS ≈ 0, анимировать только transform/opacity.
- Польза JustDay: совпадает с нашим Р2-9 (токены движения) и Р2-11/12 — подтверждает курс.
  Для **сайта/лендинга JustDay** (если будет) — готовая схема. В QML-оболочке Three.js/GSAP не нужны.
- Осторожно: это «как выглядит премиум», но п.1 и п.20 из твоих же скринов («нейрослоп»: неон,
  тёмное+один акцент, анимации при наведении везде) — не копировать слепо.
