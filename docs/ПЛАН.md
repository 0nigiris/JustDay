## Что осталось

### 1. Кем думать в оболочке, когда Claude там нельзя

**Что выяснилось.** Войти в оболочку подпиской Claude нельзя: с февраля 2026 Anthropic разрешает
такой вход только своим Claude Code и claude.ai, с апреля закрывает технически. Это не настройка,
которую мы не нашли, — это правило, и обходить его мы не будем.

**Что из этого следует.** Одной оболочки на всё не выйдет. Но нужное человеку — «кончился лимит,
работа не встала» — получается и без неё: подписка работает в Claude Code, а когда она кончилась,
работа продолжается в оболочке на других поставщиках. Склейка уже есть: лестница и `ПЕРЕДАЧА.md`.

**Шаги, по порядку.**

1. **Верх оболочки — OpenAI по его подписке ChatGPT.** OpenAI это прямо разрешает в сторонних
   оболочках, OpenCode назван по имени. Он туда уже входил, но токен просрочен — оболочка говорит
   `Token refresh failed: 401`. **Нужен он:** `opencode auth login` → OpenAI → войти своим ChatGPT.
   Дальше ставим его модель верхней ступенью и проверяем одним вопросом.
2. **Середина — Kimi K3 в облаке Ollama.** Модель у него скачана, но облако отвечает
   `Unauthorized`: нет входа. **Нужен он:**
   `~/.local/share/justday/ollama/bin/ollama signin`.
3. **Низ работает уже сейчас.** Проверено вживую: `openrouter/qwen/qwen3-coder` отвечает, местная
   `ollama/qwen3.5:9b` отвечает. Лестница приведена к этим двум, чтобы не спотыкаться о мёртвые
   ступени.
4. **Переход между оболочками одной командой** — `justday work`: смотрит, отвечает ли Claude
   Code; отвечает — открывает его, кончился лимит — открывает оболочку на живой ступени и говорит
   об этом. Делается без человека.
5. **Если захочется сильной модели в оболочке за небольшие деньги** — кодовые тарифы, которые
   прямо разрешают сторонние оболочки: GLM Coding Plan (z.ai), Kimi for Coding, MiniMax. Цены
   у разных обзоров расходятся, младшие тарифы — порядка десяти-двадцати долларов в месяц.
   **Решение его:** это его деньги, и покупать сам я ничего не буду.

### 2. Оболочка: сжатие по своей воле

Сейчас разговор сжимает сам OpenCode по своему порогу (`compaction.auto`). Хотелось другого: чтобы
модель видела, сколько места осталось, и говорила «сжимай» сама — до того, как упрётся. Разница
видна в длинной работе: автосжатие по порогу рубит посередине мысли, а по своей воле — на границе
законченного шага, и после него модель помнит не «последние 15 ходов», а то, что сама выбрала
помнить.

Что для этого есть: плагин видит расход токенов в каждом ответе (`event` → `message.updated`).
Что надо: порог в `justday-ladder.json`, строка в окне и вызов сжатия, когда места меньше порога
**и** шаг закончен.

### 3. Трей на верхнюю полосу — **нужен человек**

Hikisey предлагал перенести лоток на верхнюю полосу. Человек эту мысль отклонил: «пусть трей будет

### 6. ~~Вход в Anthropic в оболочке~~ — нельзя, и это не наша прихоть

Он пробовал войти — оболочка просит ключ API. Так и будет: в феврале 2026 Anthropic запретил
использовать вход по подписке (Pro, Max) в сторонних программах, а с апреля закрыл его технически.
Разрешены только свои: Claude Code и claude.ai.

Как теперь устроено:

- подписка работает в Claude Code — и в самом Джарвисе, который думает через него;
- в оболочке Claude появляется только с ключом API, за деньги по токенам
  (`justday secret set anthropic`);
- без ключа ступени anthropic пропускаются, и лестница один раз говорит, какие и почему.

Его лестница в оболочке теперь из того, что у него есть: OpenRouter → Kimi в облаке Ollama →
местная Qwen. В оболочке он вошёл ещё в OpenAI — эту ступень можно поставить наверх, если
окажется, что она ему нравится больше.

## Сделано

### Оболочка (пункт «Оболочка для Клода» целиком)

Своё окно не писали — взяли OpenCode и приделали к нему руль. Лестница поставщиков живёт в двух
местах, потому что это две разные вещи: `shell/opencode/justday-ladder.js` водит оболочку (кто
отвечает человеку в чёрном окне), `src/justday/fallback.py` + `daemon.py` водят самого ассистента
(кто думает над просьбами с островка).

- Вниз по лимиту, наверх по проверке: раз в четверть часа у верхнего спрашивают одним словом, и
  спрашивают в отдельной сессии и только между делами — забрать работу посередине значит её потерять.
- Мелочь уходит крошечной местной модели; «открой дискорд» — не мелочь: там надо сделать, а не
  ответить, а инструменты крошечной не даются.
- Передача эстафеты: при спуске в разговор без ответа кладётся заметка с указанием на `ПЕРЕДАЧА.md`.
- Имена моделей подновляются по таблице переименований: прошлогоднее имя роняло всю лестницу.
- Инструменты перенесены из Claude Code: было 5 умений, стало 63; MCP context7; правила —
  `instructions`; автосжатие.
- `justday shell` ставит плагин, тянет ключи из связки в окружение и открывает окно.
