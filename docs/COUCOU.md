## Что за программа
Маленький друг у выреза экрана: показывает сессии Claude Code/Cursor/Codex и т. д., «Разрешить/Отклонить/Всегда» прямо из островка, вопросы `AskUserQuestion`, чат с моделями, файл на остров → вопрос про него, Mochi уходит гулять по рабочему столу, гардероб, «OK Coucou» голосом. Очень близко к JustDay по замыслу.

## Что полезно для нас (идеи и логика — код MIT, но персонажа не трогаем)
1. **Три шлепка за 1,7 с → «головокружение»** (`windows/src/mochi/engine.ts:270–366`) — готовая модель реакций маскота: одиночный клик = тычок (если не двойной), три подряд = dizzy. Для п.15: «злится от клика, мурлычет, если водить».
2. **Глаза на сфере следуют за курсором** — приём, а не картинка; повторим на своём герое.
3. **Состояния как таблица** (цвет/тон/глаз/значок на состояние, `engine.ts:86–117`) — удобный способ сделать сменные скины.
4. **Одобрение из островка** (Разрешить/Отклонить/Всегда) и **файл на остров** — у нас уже есть; сверить их «Always».
5. **Свои звуки** — подкладываешь файл с именем звука в папку; хороший приём для скинов.
