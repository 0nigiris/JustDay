## Что за программа
Маленький друг у выреза экрана: показывает сессии Claude Code/Cursor/Codex и т. д., «Разрешить/Отклонить/Всегда» прямо из островка, вопросы `AskUserQuestion`, чат с моделями, файл на остров → вопрос про него, Mochi уходит гулять по рабочему столу, гардероб, «OK Coucou» голосом. Очень близко к JustDay по замыслу.

## Что полезно для нас (идеи и логика — код MIT, но персонажа не трогаем)
1. **Три шлепка за 1,7 с → «головокружение»** (`windows/src/mochi/engine.ts:270–366`) — готовая модель реакций маскота: одиночный клик = тычок (если не двойной), три подряд = dizzy. Для п.15: «злится от клика, мурлычет, если водить».
2. **Глаза на сфере следуют за курсором** — приём, а не картинка; повторим на своём герое.
3. **Состояния как таблица** (цвет/тон/глаз/значок на состояние, `engine.ts:86–117`) — удобный способ сделать сменные скины.
4. **Одобрение из островка** (Разрешить/Отклонить/Всегда) и **файл на остров** — у нас уже есть; сверить их «Always».
5. **Свои звуки** — подкладываешь файл с именем звука в папку; хороший приём для скинов.

### Разбор Android и phone_link (13 окт, продолжение)

Прочитаны `docs/ANDROID_LINK.md`, Android `Pairing.kt`/`Transport.kt`/`ApprovalSheetPlan.kt`, Rust `pairing.rs`/`server.rs` и `android/PERMISSION.md`; приложение и desktop-сервер не запускались.

- **Полезные принципы для собственного приложения:** возможности телефона согласуются отдельно (по умолчанию выключены); подтверждение привязано к ещё ожидающему запросу, старое нажатие ничего не делает; «разрешить» на телефоне требует экранную блокировку/биометрию; обрезанная команда доступна только для отказа; сетевой протокол ограничивает размер сообщений, ожидание первого приветствия и число подключений. Небольшие правила вынесены в чистые функции и тестируются без телефона.
- **Связь:** Coucou пытается подключиться напрямую в локальной сети с TLS и закреплённым отпечатком сертификата. При отсутствии LAN может идти через дополнительный relay; для сна Android отдельно учтены Doze, редкие проверки и поиск ПК через mDNS. Это не готовый путь для JustDay: в Coucou desktop слушает LAN (0.0.0.0), а правило JustDay — наши порты только на 127.0.0.1. Не переносить такую схему без отдельного решения и архитектуры, соблюдающей это правило.
- **Что можно перенести как замысел, не копируя персонажа:** экран состояния задач, безопасные карточки подтверждений/ответов и отдельные разрешения для чата/деталей. Для JustDay важнее его собственный запрос: отдельные вкладки «JustDay» и «Стримдек», Tailscale, удалённая очередь `justday terminal` и видимый прогресс (п.23). Отдельно сверить, какие сообщения и поля действительно нужны, не отправлять файлы, ключи и лишние пути.
- **Ограничение лицензии:** код телефона и `phone_link` MIT. `android/PERMISSION.md` описывает отдельное разрешение только для Coucou Android и требует бесплатного приложения и одобрения автора перед публикацией. Это разрешение не распространяется на JustDay. Персонажа Mochi, имя Coucou, иконку, звуки, картинки и макеты не использовать; создать свой интерфейс и графику.
- Практический вывод для п.23: брать безопасность протокола и проверяемость состояний как ориентир; не брать сетевой сервер напрямую и не переносить UI/ассеты. Android-проект JustDay проектировать отдельно, с безопасным транспортом и без широкого bind.
