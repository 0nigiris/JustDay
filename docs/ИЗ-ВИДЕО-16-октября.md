## Берём

### 1. Thinking Orbs — живые шары состояний для острова ⭐
- Что: 9 анимированных «шаров-мыслей» для ИИ-интерфейсов — working, searching, solving, listening,
  connecting… Две подстроенные размерности, светлая/тёмная тема, reduced-motion, пауза, когда не видно.
- Лицензия MIT, npm `thinking-orbs@0.3.1`, код — github.com/Jakubantalik/thinking-orbs, демо orbs.jakubantalik.com.
- Почему подходит: рисуется на обычном 2D canvas без WebGL. В Quickshell есть `Canvas` с тем же
  JS-API (`getContext("2d")`) → логику отрисовки можно перенести в QML почти дословно, без браузера.
- Куда: островок. Сопоставление: слушаю → listening, думаю → solving, ищу в сети → searching,
  работает задача/терминал → working, подключаюсь (телефон/Telegram) → connecting.
- Проверить: CPU в простое (у острова бюджет), reduced-motion из настроек KDE, контраст на тёмных обоях.
- Из видео v02 (ты сам пометил «useful for JustDay»).

### 2. Утренний звонок со сводкой
- В видео (v01) это делают через Bland AI (платный API). **Тебе Bland не нужен**: в JustDay уже есть
  Telnyx-телефон (`phone/`) и свой голос. Шаг цикла в 09:00 (или когда проснулся по острову):
  почта + календарь + задачи + «что студия сделала за ночь» → голосом, звонком или голосовым в Telegram
  (`justday telegram voice` уже умеет).
- Опция «только голосовое» — бесплатно; «звонок» — копейки по тарифу Telnyx.

### 3. Режим «учитель языка»
- Карусель @reelsmentor_ai: 7 промптов — личный преподаватель, словарь по темам, грамматика без
  терминов, разговорная практика, бытовые сценки (аэропорт, врач, магазин), разбор ошибок,
  ежедневное погружение.
- Для JustDay это просто персона/сценарий: голосом «давай английский» → диалог, ошибки — в заметки,
  завтра повторить. Код почти не нужен: голос, STT и память уже есть.

### 4. Запасной «мозг», когда кончился лимит — FreeLLM API
- github.com/tashfeenahmed/freellmapi: один OpenAI-совместимый адрес поверх бесплатных тарифов
  (Gemini, Groq, Mistral, OpenRouter…), сам переключается при лимите.
- У JustDay уже есть лестница и Ollama. Смысл — ступень между «Claude кончился» и «локальная 9B»:
  быстрее и умнее локальной для простых ответов. Цифры из видео («миллиарды токенов») — реклама.
- Правила: только 127.0.0.1, ключи бесплатных тарифов — в связке ключей, личное (почта, заметки)
  туда **не** отправлять — только то, что и так можно отдать облаку.
- Перед установкой: открыть репозиторий, проверить лицензию и что он шлёт наружу.

### 5. Strix — проверка безопасности перед выпуском
- ИИ-пентест (v31): агенты атакуют твоё приложение и приносят доказательства, а не догадки.
- JustDay слушает порты (сервер, телефон, Tailscale) → прогнать Strix по локальному серверу перед
  публичным релизом. Разово, не постоянно.

### 6. Антислоп для текстов, которые видят люди
- stop-slop / humanizer (v21, v40, v43): убирают признаки ИИ из текста — «это не X, это Y», длинные
  тире, тройки прилагательных, «погрузимся». Для README, описаний релизов, писем.
- Можно не ставить скилл, а положить список признаков (он есть в `РАЗБОР.md` §5) в правила.

## Связка со студией (на будущее)
- Студия — отдельный репозиторий, как Nonstop. Когда выложим на GitHub: `justday parts` получает
  внешнюю часть «studio» (проверка — папка студии есть; поставить — `git clone`), а не extra пакета.
- Студия уже шлёт итоги ночи в Telegram через `justday telegram send`. Карточка на острове
  «студия: 5 клипов готовы» — следующий шаг.
- Цикл JustDay не годится для студии: у шага таймаут 30 мин, нарезка идёт часами → у студии свой
  таймер systemd (`studio-clips.timer`).
