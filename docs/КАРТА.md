# Карта JustDay

Для модели, которая пришла на смену и видит проект впервые: где что лежит и как ходит запрос.
Описание отдельного файла — его первая строка (docstring у Python, первый комментарий у QML).
Здесь только то, чего по одному файлу не понять: какие части связаны и через что.

## Два процесса

- **Демон** (`justday.service`, `src/justday/daemon.py`) — голос, мозг, музыка, почта, всё, что
  думает. Python.
- **Островок** (`justday-ui.service`, `island/shell.qml`) — всё, что видно: Dynamic Island, док,
  трей, меню, настройки. QML на Quickshell.

Они разговаривают через управляющий сокет: одна строка JSON на запрос. Островок шлёт
`JD.send({cmd: …})`, демон отвечает в `commands.py`, где на каждую команду есть `_cmd_<имя>`.
Обратно демон публикует события (`daemon.publish`), и островок раскладывает их в свойства `JD`.

## Путь голосовой просьбы

1. `hearing.py`: кнопка, слово пробуждения (`namespot.py`) или «договорил» (`turn.py`) → запись.
2. `stt.py`: речь превращается в текст (faster-whisper).
3. `fastpath.py`: простые команды («открой», «громче», «пауза») выполняются без модели, быстрее
   полсекунды. `chitchat.py` так же отвечает на «привет». `volume.py`, `scenes.py` — тоже мимо модели.
4. `dispatch.py` решает, какая модель и с каким усилием думает. `ladder.py` спускает на
   следующую ступень, когда кончился лимит. `fallback.py`, `freellm.py` и `localllm.py` — эти ступени.
5. `brain.py`: Claude Code через Agent SDK, одна долгая сессия. Характер и правила лежат в
   `brain/PERSONA.md` и `persona.py`, разрешения — в `brain/settings.json` (не ослаблять).
6. `speech_lane.py` + `tts.py`: ответ вслух; `approvals.py` — «можно?» кнопкой в островке.

## Дорожки демона (`*_lane.py`)

Каждая дорожка — примесь к демону с одной областью: `music_lane` (музыка и плеер, сам плеер в
`media.py`), `video_lane`, `reminder_lane` (над `reminders.py`), `calendar_lane`, `remote_lane`
(телефон, Telegram), `speech_lane`. Фоновые петли — `background.py`, хозяйство — `housekeeping.py`.

## Настройки

`config.py`: значения по умолчанию плюс `~/.config/justday/config.toml`. Новая настройка — ключ в
`DEFAULTS` и строка в `island/SettingsView.qml` (`Row { … Field { key: "раздел.ключ" } }`).
Окно настроек читает и пишет их через `manage.py`. Секреты — только `config.secret()` (связка
ключей, на Windows — keyring), никогда в TOML.

## Островок

- `JD.qml` — синглтон общего состояния: соединение с демоном, тема, токены анимаций
  (`durFast`, `durBase`, `durSlow`, `dur(n)`), перевод `JD.tr`. Читается почти всеми файлами.
- `shell.qml` — окна и режимы. Сами виды вынесены по файлам (`*View.qml`); строки «Вынесено из
  shell.qml (Р-80)» означают именно это.
- Свёрнутая полоска — `PeekView.qml` (виджеты из `island.peek`), развёрнутая — `ExpandedView.qml`.
- Док — `DockView.qml` + `dock.py`; трей — `TrayView.qml`; поиск — `SpotlightView.qml`
  (+ `launcher.py`, `filesearch.py`); старое меню — `MenuView.qml`, его снятие (Р2-8) ждёт его взгляда.
- Маскот — `Mascot.qml` (шар со скином, `data/mascots/*`), `Buddy.qml` (без скина), `Orb.qml`.
- Общие кирпичи: `Pressable` (нажатие), `Icon` (lucide), `JSlider`, `Roll` (катящиеся цифры).
- Перевод интерфейса — `island/i18n/en.json`; тест `test_english_complete` упадёт без него.

## Оболочки для работы

- `terminal.py`, `terminal_ui.py` — своя оболочка: один терминал, лестница движков
  (`docs/ОБОЛОЧКА.md`).
- `shell.py` и `shell/opencode/` — то же поверх OpenCode.

## Windows

`config.WINDOWS`. Там живёт только островок (`JUSTDAY_ISLAND_ONLY=1`). Linux-команды переводит
`winaudio.run` (быстрый путь) и `island/host.py` (кнопки островка). Обновляется сам exe
(`manage.exe_update_status`, `modules._exe_update`), подробности в `docs/WINDOWS.md`.

## Проверки и съёмка

- `tests/` — тесты на то, что сломалось у человека (см. CLAUDE.md).
- `scripts/qmllint-ratchet.sh ФАЙЛЫ…` — без аргументов не проверяет ничего.
- `scripts/film.sh` и `scripts/shot.sh` снимают вид без экрана. Они берут данные живого демона
  (имя человека тоже), поэтому снимки наружу делаются на чистом доме.
