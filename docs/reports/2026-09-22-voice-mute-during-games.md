# Репорт: отключение голоса JustDay во время игр

Дата: 2026-09-22
От: пользователь (через JARVIS-сессию)

## Проблема 1 — лаги в игре при озвучке

Когда у пользователя запущена игра, синтез речи (TTS) вызывает лаги/просадки FPS
в этой игре. Судя по всему, локальный голосовой движок (Qwen3-TTS,
`justday-voice.service`) грузит GPU (CUDA) одновременно с игрой, и это создаёт
заметный конфликт за ресурсы видеокарты.

Пользователь просит:
- либо решить саму проблему с производительностью (не грузить GPU так сильно
  во время озвучки, или переключаться на менее прожорливый движок/CPU, пока
  игра активна),
- либо дать возможность просто отключать голос по требованию.

## Проблема 2 — нужна ручная/автоматическая функция отключения голоса

Запрошена возможность отключать голосовые ответы JustDay (получать только
текст в UI острова) по команде пользователя, и в идеале — автоматически,
когда обнаружено, что запущена игра (например, активное полноэкранное окно
известного игрового процесса, или явный список "игровых" desktop id).

Технически: сейчас озвучивается каждый текстовый ответ ассистента без
возможности пометить конкретный ответ как "только текст" изнутри диалога —
это решение полностью на стороне демона (`justday.service`), у ассистента
(Claude Code / модели, отвечающей в разговоре) нет флага "не озвучивать этот
ответ".

Предложение:
1. Добавить команду/тумблер, например `justday voice mute` /
   `justday voice unmute`, или пункт в `justday persona` / `justday config`
   (`voice.enabled = false`), который отключает TTS-вывод демона, оставляя
   обычную текстовую работу острова.
2. (опционально) Автоопределение активной игры через `justday windows list`
   /список известных игровых desktop id из `justday games`, и автоматическое
   заглушение голоса, пока такое окно активно и в фокусе — с возвратом голоса,
   когда игра закрыта/свёрнута.

## Контекст расследования (на случай, если пригодится)

В этой же сессии разбирались с голосом ElevenLabs (смена голоса на
Maxim/другие) — там были отдельные проблемы с API-ключом (сначала случайно
стёрт `justday voice key` без stdin, потом создавался с недостаточными
правами — нужен как минимум `Text to Speech: Access` и `Voices: Read`).
Это уже почти не связано с проблемой 1 и 2 выше, но всплыло в этом же
диалоге — сами настройки ElevenLabs сейчас рабочие, `paplay` тестовый звук
и TTS-запрос проходят без ошибок на уровне демона. Отдельно всплыла
проблема с реальным звуковым выводом (наушники в разъёме ПК не издают
звук ни от системного `paplay`, ни от TTS) — это, похоже, аппаратная/ALSA
проблема, не относящаяся к JustDay напрямую, но пользователь может
упомянуть её тоже.
