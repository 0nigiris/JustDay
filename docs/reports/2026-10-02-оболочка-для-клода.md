# Оболочка для Клода: план

Задача, как её сказал человек: обычный Claude Code — это рельсы. Нейросеть в нём не может сменить
себе модель, не может поднять или опустить усилие, не может попросить сжать контекст и не может,
когда у неё кончается лимит, перейти на другую нейросеть и продолжить работу. Всё это делает
человек руками. Нужно, чтобы это делала она сама, а человек только смотрел.

Вид — как у OpenCode: чёрное окно, один акцент, строка состояния снизу. Не терминал по умолчанию.

## Что уже существует и что из этого брать

| Что | Что умеет | Берём |
| --- | --- | --- |
| Claude Agent SDK (python) | `set_model()` прямо посреди разговора, управляющий протокол, хуки, usage в каждом ответе | да — на этом строим ядро |
| claude-code-router | локальный прокси, говорящий по API Anthropic; `/model поставщик,модель`; маршруты default / think / longContext; OpenRouter, Ollama, Gemini, DeepSeek | да — идею и, возможно, сам пакет |
| OpenCode | готовый чёрный TUI, много поставщиков, вход по подписке Claude | проверить первым: может, половину работы делать не надо |
| OpenRouter | сам переключает поставщика при отказе или лимите | да — как нижний слой запаса |

## Четыре умения, ради которых всё затевается

1. **Сменить себе модель.** Инструмент `модель(лёгкая|сильная)`. В SDK это `set_model()` —
   разговор не рвётся, контекст остаётся.
2. **Сменить себе усилие.** Инструмент `усилие(низкое|среднее|высокое)` — бюджет размышления на
   запрос. Для «открой дискорд» высокое усилие это выброшенные деньги.
3. **Сжать контекст.** Инструмент `сжать()`. Оболочка видит расход токенов из каждого ответа
   (точное число, а не догадка) и сама говорит модели: «осталось 15% до предела» — решает модель.
4. **Перейти на другую нейросеть.** Когда лимит Claude кончается: модель дописывает `ПЕРЕДАЧА.md`
   (что делала, что закоммичено, какой следующий шаг), оболочка гасит сессию и поднимает новую на
   запасном поставщике, первым сообщением — этот файл. Кими или Грок приходит и видит задачу.

## Порядок работ

- **Фаза 0 — вечер, час.** Поставить OpenCode, войти его ключами (Groq, OpenRouter), прожить в нём
  один рабочий заход. Если он закрывает смену модели и поставщика — строим оболочку поверх него, а
  не с нуля. Это самая дешёвая проверка, и её надо сделать до всего остального.
- **Фаза 1 — маршрутизатор.** Локальный прокси на 127.0.0.1 (наружу не смотрит), ключи в связке
  ключей, а не в конфиге и не в памяти. Даёт запасного поставщика любому клиенту, в том числе тому
  Claude Code, в котором мы сидим сейчас.
- **Фаза 2 — ядро оболочки.** Свой цикл на Agent SDK, четыре инструмента выше, счётчик токенов и
  денег в строке состояния.
- **Фаза 3 — передача эстафеты.** `ПЕРЕДАЧА.md`, автоматический перезапуск на запасном, проверка:
  оборвать лимит посреди работы и убедиться, что работа продолжилась.
- **Фаза 4 — внутрь JustDay.** Страница «Клод» показывает живые сессии (уже есть), оболочка живёт
  службой, островок говорит, когда модель сменилась.

## Чего не делать

- Не выносить управляющий порт наружу: только 127.0.0.1.
- Ключи — в связке ключей. Не в исходниках, не в конфиге, не в памяти ассистента.
- Опасные действия сохраняют подтверждение. Смена модели и сжатие контекста — не опасные,
  подтверждения не требуют.
