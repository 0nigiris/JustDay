# Подключение: всё, что нужно сделать руками

Одна страница вместо «что от тебя требуется» в десяти разных ответах. Каждый кусок независим:
делай в любом порядке, непод­ключённое просто не работает, остальное работает.

Проверить, что уже подключено, можно в любой момент:

```sh
justday doctor --quick
```

Правило для всех ключей на этой странице: **ключ набираешь ты, а не я**. Он уходит в связку
ключей рабочего стола (`secret-tool`), оттуда его читает демон. Ни в конфиге, ни в исходниках, ни
в моей памяти его нет и не будет.

## 1. Google Календарь

**Чтение уже работает** — ссылка подключена, `justday calendar today` отвечает. Если нужно
добавить ещё один календарь (рабочий, общий с кем-то):

1. [calendar.google.com](https://calendar.google.com) → шестерёнка → **Настройки**.
2. Слева, в списке «Настройки моих календарей», выбери нужный календарь.
3. Пролистай до **«Секретный адрес в формате iCal»**, нажми глаз, скопируй ссылку.
4. Вставь сюда:

```sh
justday calendar setup 'ВСТАВЬ_ССЫЛКУ'
justday calendar week          # проверка: должны появиться события
```

Ссылка секретная: кто её знает — видит твой календарь. Она уходит в связку ключей.

**Чего пока нет:** записи. Секретная ссылка — только на чтение, поэтому «Джарвис, поставь встречу
на четверг» он выполнить не может. Для этого нужен полноценный доступ (OAuth) — это пункт 20
плана, делаю я, от тебя там будет одно нажатие «Разрешить» в браузере.

## 2. Telegram — бот

Это будет запасная оболочка: пишешь боту с телефона из любой точки мира, он отвечает тем же
Джарвисом. Токен можно получить **сейчас**, даже до того, как я допишу код, — он подождёт в связке
ключей.

1. В Telegram найди **@BotFather**.
2. `/newbot` → имя (любое, например `Jarvis`) → username (должен кончаться на `bot`,
   например `onigiri_jarvis_bot`).
3. Он пришлёт строку вида `8123456789:AA...` — это токен. **Мне его не показывай.**
4. Положи его в связку ключей (команда спросит значение и не покажет его на экране):

```sh
secret-tool store --label "JustDay: telegram_token" service justday key telegram_token
```

5. Напиши своему боту `/start` — иначе он не имеет права писать тебе первым.

Проверка, что токен лёг (печатает только «да/нет», не сам токен):

```sh
secret-tool lookup service justday key telegram_token >/dev/null && echo есть || echo нет
```

## 3. Telnyx — звонки на чужие номера

Счёт у тебя уже есть (видно по снимку: `PRETRIAL`). Дальше по шагам, в том же порядке, как в
боковом меню портала.

**Шаг 1. Снять ограничение пробного режима.** Значок `PRETRIAL — UPGRADE` вверху справа. В
пробном режиме звонить можно только на свой же подтверждённый номер, и купить номер нельзя.
Нажми **UPGRADE**, пройди проверку личности (паспорт/ID) и положи на счёт минимум — обычно
хватает 10 $. Проверка занимает от десяти минут до суток.

**Шаг 2. Купить номер.** Боковое меню → **Numbers** → **Buy numbers** (на главной это та же
кнопка в карточке «Numbers»).
- *Country* → **Spain**, *Number type* → **Local**.
- Выбери любой из списка, **Add to cart** → **Place order**.
- Цена: около 1 $ в месяц.
- **Платить нажимаешь ты.** Я могу довести до этой кнопки и остановиться — это наше правило.

**Шаг 3. Создать приложение для голоса.** Боковое меню → **Voice** → **Call Control** (или на
главной карточка «Voice» → **Create application**).
- Имя: `JustDay`.
- *Webhook URL* пока оставь пустым — его пропишу я, когда подниму приёмник.
- Сохрани. В списке появится **Connection ID** — он понадобится.

**Шаг 4. Привязать номер к приложению.** **Numbers → My numbers** → твой номер → вкладка
**Voice** → *Connection* → выбери `JustDay` → Save.

**Шаг 5. Ключ API.** Правый верхний угол, значок человечка → **API Keys** → **Create API Key**.
Скопируй ключ (он показывается один раз) и положи в связку:

```sh
secret-tool store --label "JustDay: telnyx" service justday key telnyx
secret-tool store --label "JustDay: telnyx_number" service justday key telnyx_number   # сам номер, +34…
secret-tool store --label "JustDay: telnyx_connection" service justday key telnyx_connection
```

Что это даст: «позвони в ближайшую кебабню и спроси, до скольки они сегодня» — примерно
0,005–0,007 $ за минуту плюс доллар в месяц за номер. Код с моей стороны — пункт 23 плана.

## 4. Kickbacks — короткий ответ: тебе он не нужен

Я распаковал пакет и прочитал установщик, не запуская его. Его собственное описание:
«npx installer for the Kickbacks v2 **VS Code/Cursor extension**». Он скачивает `.vsix`, сверяет
сумму и ставит расширение в VS Code или Cursor — больше ничего.

Значит: **в терминальном Claude Code он не виден и не считает ничего.** Платят там за работу
внутри VS Code/Cursor, а ты работаешь в терминале. Чтобы он что-то приносил, пришлось бы
пересесть в VS Code и кодить там — ради этого менять привычку смысла нет.

Если всё-таки захочешь попробовать — команда лежит в плане, пункт 5, вместе с проверенной суммой
файла.

## 6. Голос

Сейчас говорит silero с процессора: мгновенно и без сюрпризов. Ты сказал «нравится, но идеалу нет
предела» — значит следующий шаг не срочный.

Когда захочешь лучше, нужен один ключ. Варианты по порядку разумности:

| кто | за что платишь | как звучит |
|---|---|---|
| **ElevenLabs** | ~5 $/мес за 30 тыс. знаков | лучший русский, задержка ~0,3 с |
| **Fish Audio** | дешевле, есть бесплатный лимит | хорошо, можно клонировать голос по минуте записи |
| свой на карте | бесплатно | у тебя не влезает в 12 ГБ рядом со слухом и местной моделью |

Ключ кладётся так же:

```sh
secret-tool store --label "JustDay: elevenlabs" service justday key elevenlabs
```

Код под это — пункт 13 плана.
