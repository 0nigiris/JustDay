**Проверить руками**
- Звуки: нравятся ли (клик на всех кнопках, переключатели); не нравятся — выключатель «Звуки интерфейса».
- Повтор отрезка A–B: в видео (пилюля «A–B» у кнопки повтора) и в карточке музыки.
- «Быстрый ответ»: не обрывает ли на «поставь таймер на…»; через день-два `justday latency`.
- Вставка эмодзи/буфера, фокус в игре, игровой режим без тоста, страница «Медиатека», ссылка из микса в Spotlight и «включи из буфера», таймер с паузой.
- Сообщение с телефона/Telegram в чат без звука; фраза с длинной паузой (при отказах смотреть `score` в `listen_rejected`).
- «Как меня звать» + «Слушать 4 секунды»; микшер (чипы, щелчок по OSD, «открой микшер»).
- Кнопки в уведомлении: `notify-send -A ответ=Ответить -A позже=Позже "Тест" "текст"`; кнопка «Показать» в тосте о сбое.
- Чипы модели в чате, волна голоса при настоящей речи, сессия, ждущая разрешения на правку, `gio list` корзины для `music_untrash`.
