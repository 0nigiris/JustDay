# Команды `justday`

Список всех подкоманд и по строке о каждой. Подробности — `justday <команда> -h`. Файл сверяется с
парсером тестом (`tests/test_commands_doc.py`): добавил подкоманду — добавь сюда, иначе тест упадёт.


## Голос и демон

- `justday daemon` — run the voice daemon (normally via systemd)
- `justday toggle` — hotkey action: start/finish listening, or interrupt speech
- `justday stop` — stop speaking and interrupt the current task
- `justday ask` — send a text command (as if spoken)
- `justday say` — speak text through JustDay's voice
- `justday approve` — allow the action JustDay is asking about
- `justday deny` — deny the action JustDay is asking about
- `justday latency` — сколько проходит от конца фразы до музыки (по журналу)
- `justday report` — собрать отчёты о сбоях в один архив без личного (чтобы отправить разработчику)
- `justday chat` — открыть окно чата с ассистентом (ответы в нём не озвучиваются)
- `justday compose` — keyboard shortcut: open the island's text field (takes the selected text along)
- `justday new-session` — forget the current conversation (memory is kept)
- `justday logs` — show recent events
- `justday status` — состояние демона: что слушает, чем занят, какая сессия и модель
- `justday suitcase` — чемодан: перенос настроек и ключей на другой ПК одним файлом под паролем (export ФАЙЛ | import ФАЙЛ)
- `justday chats` — отдельные задачи-чаты: find ТЕКСТ (есть ли готовая) | pin ID | unpin ID (закреплённые не уходят в архив)
- `justday ladders` — лестницы: кто работает сейчас и кто подхватит (нейросеть, голос)
- `justday module` — отдельные части JustDay: list | restart ID (остров только перерисовывается, док остаётся)
- `justday restart` — restart the daemon and start a fresh conversation (after model changes)
- `justday wake` — кто будит ассистента и сколько раз впустую
- `justday voice` — voices: list | design NAME DESCRIPTION | record SECONDS | clone NAME WAV TEXT | delete ID | preview TEXT | speed 1.2 | volume 80 | eleven [VOICE_ID] | key (reads stdin) | mute | unmute | games [on|off]
- `justday voiceprint` — personal voice profile: status | enroll | record KIND INDEX SECONDS | finish | reset | mode off|wake|always
- `justday hotkey` — глобальные сочетания: get показывает все, set --clip Meta+V --apps 'Alt+Space' меняет названные (пустая строка снимает клавишу, остальные не трогаются)
- `justday autostart` — start JustDay with the session: on | off | status
- `justday setup` — first-run wizard: model, mail, voice, buttons
- `justday version` — версия установленного JustDay
- `justday update` — update JustDay from GitHub (git pull + install.sh); --check only looks
- `justday doctor` — check every component
- `justday crashlog` — сохранить отчёт о сбое службы (`justday crashlog <служба>`, его зовёт systemd после падения)
- `justday test` — test one component
- `justday config` — get / set a setting: config set audio.earcons false
- `justday secret` — store an API key / password in the desktop keyring
- `justday settings-data` — JSON snapshot for the Settings window
- `justday model` — which model drives the agent: list | status | use PROVIDER [MODEL] | signin (free Ollama cloud)
- `justday models` — что держит память: слух, голос; free — отпустить сейчас
- `justday tokens` — во что обходится разговор: токены и деньги по дням
- `justday memory` — show where JustDay's memory lives / print it; `justday memory tidy` — остывшие дела из оперативной памяти в долгую (`ДОЛГАЯ.md`) и обратно, шаг цикла «Свести память»
- `justday persona` — the assistant's character: `justday persona` shows it; `justday persona friend|jarvis|calm|custom [swearing=on|off] [live=on|off]`

## Оболочка, работа и связь

- `justday shell` — open the OpenCode window with the JustDay provider ladder
- `justday terminal` — своя оболочка: один терминал, лестница движков
- `justday work` — сесть за работу: Claude Code, пока он отвечает, иначе оболочка
- `justday night` — «я спать»: задача уходит работать на ночь в отдельную службу, машина переходит в режим сервера, утром — письмо; без слов — продолжает очередь из ПЕРЕДАЧА.md и ПЛАН.md
- `justday server` — режим сервера: экраны гаснут, музыка встаёт на паузу, машина не засыпает, а работа идёт. on | off | status
- `justday cycle` — цикл ассистента: свой круг дел, пока он свободен (шаги — `[[cycle.steps]]` в config.toml; по умолчанию обновить JustDay в 05:00, проверить части в 05:30 и раз в 3 ч расшифровать присланные видео). list | run «Имя» — выполнить сейчас | log [ГГГГ-ММ-ДД] — что сделал за день
- `justday claude` — Claude Code worker sessions
- `justday job` — long commands in the background, so the assistant stays free: `justday job start "Обновление системы" -- jii update --json` · list · log ID · stop ID
- `justday telegram` — телеграм-бот: голосом или текстом ему на телефон, где бы он ни был
- `justday reach` — дотянуться до человека, когда его нет за компьютером: письмо — обычное, --urgent — ещё и звонок на телефон
- `justday call` — позвонить на номер и сказать: justday call +34612345678 «текст»
- `justday phone` — the phone through KDE Connect: list | notify TEXT | send FILE_OR_URL | ring; `pair [адрес]` — QR для приложения remo32 на телефоне: камера открывает его, и адрес не надо набирать
- `justday portable` — собрать флешку: воткнул в чужой компьютер, поработал, вынул — следов не осталось

## Экран и окна

- `justday ui` — show the assistant on screen: the island on Wayland, the fallback panel elsewhere (decided at every login; ui.face pins it)
- `justday panel` — the fallback panel for desktops without the island (X11, Plasma 5, GNOME)
- `justday edit` — режим правки в островке: значки в доке дрожат и переставляются; toggle (по умолчанию) | on | off
- `justday apps` — find/launch desktop applications
- `justday games` — list/launch installed games (Steam, Heroic)
- `justday windows` — list/focus/close/minimize windows (KWin)
- `justday click` — щёлкнуть в точке экрана (X11: xdotool; на Wayland щелчки идут через kwin-mcp)
- `justday keys` — нажать сочетание клавиш: justday keys ctrl+s (X11: xdotool)
- `justday screenshot` — capture the screen as a small JPEG and print its path
- `justday guard` — предупреждение перед выключением компьютера: status | on | off
- `justday session` — the open applications: save | close [--keep NAME] | restore | list
- `justday launch` — поиск программ: без запроса открывает лаунчер в островке, с запросом запускает первое подходящее
- `justday dock` — док: список, pin/unpin, go N (Meta+N — N-я программа слева направо)
- `justday menu` — меню приложений в островке (клавиша Windows)
- `justday popups` — чьи всплывашки с уведомлениями: island (только остров) | system (ещё и плазмы)
- `justday qr` — QR-код в терминале: `justday qr https://…` или `justday qr --wifi ИМЯ` (пароль спросит скрыто); то же — вкладка «QR» в панели островка
- `justday transcript` — видео → текст → выжимка: `justday transcript ССЫЛКА_ИЛИ_ФАЙЛ`; звук качает yt-dlp, текст пишет местный Whisper, выжимку — местная модель; файл в `docs/видео/ДАТА-имя.md`. Инстаграм без входа не отдаёт — тогда скачать файл самому и дать путь. видео-файл можно просто бросить в папку `~/Videos/Для-Джарвиса` — цикл расшифрует и уберёт в «Готово»; последняя строка выжимки — вердикт «полезно / частично / не нужно». `--later ССЫЛКА` — в очередь (без аргументов — показать её), `--queue` — разобрать; очередь разбирает шаг цикла «Расшифровать присланные видео» раз в 3 ч, когда за машиной никого
- `justday load` — нагрузка машины: процессор, память, диск, сеть, температуры, тяжёлые программы
- `justday tools` — открыть панель в островке: apps (Spotlight) | emoji | clip | mixer | load | widgets
- `justday emoji` — выбиралка эмодзи: поиск по-русски, вставка в то окно, где курсор (без запроса открывает сетку на островке)
- `justday clip` — история буфера обмена; пароли в неё не попадают
- `justday recent` — recently used files and Claude Code projects
- `justday pin` — «раз и навсегда»: `pin СЛОВО = ЗАПРОС` (дальше `play СЛОВО` играет ровно ЗАПРОС, поиск не перебьёт); `pin --list`, `pin --remove СЛОВО`
- `justday history` — что играло в последнее время (для «включи то, что я слушал»); включить — `justday play <исполнитель название>`
- `justday term` [папка] — окно терминала, какой стоит ($TERMINAL, kitty, konsole, …); команду не принимает нарочно: мозгу `justday` разрешён без вопроса
- `justday said` [слова] [-n 20] — прошлый разговор с поиском по словам, от новых к старым («что я тебе говорил про …»); почта и похожее на пароли не выводятся
- `justday parts` — необязательные части окружения (речь, голос, CUDA): `justday parts` показывает, что стоит; add/remove доставляет и убирает

## Дела и почта

- `justday timer` — set a timer: `justday timer 10m чай` · `justday timer` lists what is set
- `justday alarm` — set an alarm: `justday alarm 7:30 подъём` [--daily] · `justday alarm` lists them
- `justday reminders` — what is waiting: list | cancel [timer|alarm|ID]
- `justday plan` — планы в Obsidian: add | list | done | open
- `justday promise` — что он кому обещал: add «текст» [--to кому] [--due срок] | list [кому] | find слова | done номер
- `justday nudges` — что ассистент сказал первым за день: `justday nudges [YYYY-MM-DD]`
- `justday diary` — страница дня в Obsidian: чем занимались, что закрыли, во что обошлось
- `justday note` — заметка в Obsidian: justday note «Заголовок» текст…
- `justday watch` — присмотр: `watch done` — дело на сегодня сделано, до завтра про игру не спрашивать
- `justday inbox` — сообщения, оставленные с телефона: list | add | reply ID текст | clear
- `justday scene` — сценарии: list | run <имя> | add <имя> | forget <имя>
- `justday briefing` — (опция --send) утренняя сводка: напечатать или голосовым в Telegram (шаг цикла в 09:00, по умолчанию выключен)
- `justday habits` — what the user usually asks around this hour (for «как обычно»)
- `justday calendar` — private calendar from iCal links: setup | today | tomorrow | week
- `justday mail` — private mail lane (local model): setup | check | read N
- `justday contacts` — address book JustDay learns: list | find QUERY | set NAME key=value… | forget NAME
- `justday compose-mail` — draft an e-mail locally (confirmed by the user); the address stays private
- `justday confirm-message` — show a message draft on the island and wait for the user's answer (run it BEFORE opening the messenger)

## Медиа и студия

- `justday play` — play music: finds it on YouTube, downloads the audio, plays in JustDay's player (count=N for several songs, playlist=1 for an album/playlist, shuffle=1, next=1 / add=1 to queue); also a file or a folder
- `justday video` — play a video (search words or a link); --where island|window|browser, or say it in the words themselves («в островке»); otherwise the setting decides (Settings → Музыка и видео)
- `justday player` — JustDay's player: status | pause | resume | toggle | next | prev | restart | stop | seek SECONDS | volume 0-130 | repeat off|all|one | shuffle on|off | jump INDEX | color жёлтый|#ffd23f|auto (the colour of the track on the island)
- `justday studio` — local creative studio: status | image | edit | upscale | nobg | video | animate | music | 3d | speech | subs | cut | join | audio | burn | vertical | nopause | speed | gif | slideshow | info | jobs | job ID | stop (key=value options)
