# Политика конфиденциальности JustDay

Редакция от 13 октября 2026 года.

JustDay — программа, которая работает на вашем компьютере. У проекта **нет своего сервера**: автор
JustDay не получает ни ваших просьб, ни записей голоса, ни журналов, ни статистики использования.
Всё, что JustDay помнит, лежит в файлах в вашей домашней папке. Наружу данные уходят только в
сторонние сервисы — и только в те, которые вы сами включили или которые нужны для вашей просьбы.
Ниже перечислено, какие это сервисы и что именно туда попадает.

Подробная таблица с техническими деталями — `docs/MANUAL.md`, раздел 2. Если они расходятся с
этим документом, верен тот, что новее; об ошибке напишите (контакты в конце).

## 1. Что остаётся на компьютере

| Что | Где | Сколько хранится |
|---|---|---|
| Звук с микрофона | не сохраняется: распознаётся на месте (Whisper) | — |
| Записи для настройки под ваш голос и отпечаток голоса | `~/.local/share/justday/voiceprint/` | пока не удалите |
| Журнал просьб, ответов и действий | `~/.local/state/justday/events.jsonl` (права 0600) | сам не обрезается |
| Логи и отчёты о сбоях | `~/.local/state/justday/justday.log`, `crashes/` | лог — до четырёх файлов по кругу, отчётов — последние 20 |
| История буфера обмена | `~/.local/state/justday/clipboard.jsonl` и картинки рядом (0600) | до «Забыть всё»; похожее на пароль не записывается |
| Чаты с ассистентом и вставленные в них картинки | `~/.local/share/justday/chats/` | пока не удалите чат |
| Память ассистента, профиль, контакты | `~/.local/share/justday/brain/`, `contacts.json`, папка памяти Claude Code | пока не удалите |
| Индекс имён файлов для поиска, недавние программы | `~/.local/state/justday/` | обновляется сам |
| Последняя геопозиция (только если вы транслируете её боту в Telegram) | один файл (0600), без истории | считается устаревшей через короткое время |
| Пароли и ключи сервисов | связка ключей рабочего стола (KDE Wallet / GNOME Keyring) | пока не удалите |

Распознавание речи, локальная модель (Ollama), студия картинок (ComfyUI), почта (IMAP + локальная
модель) и календарь работают на компьютере. Наш управляющий сокет и порты слушают только
127.0.0.1 — с другой машины к ним не подключиться.

## 2. Что уходит наружу и кому

**Мозг ассистента — Anthropic (Claude Code).** Когда просьба доходит до мозга, в Anthropic уходит
распознанный текст просьбы, профиль и файлы памяти (это его контекст), результаты инструментов
(вывод команд, прочитанные файлы, страницы из сети, снимки экрана — только когда мозг сам решил
посмотреть на экран), сообщения и картинки из окна чата. Мгновенные команды («громче», «открой
дискорд», таймеры) выполняются без мозга. Почту и календарь мозгу читать запрещено настройками.
Как долго Anthropic хранит эти данные и используются ли они для обучения, решают условия Anthropic
и переключатель в [настройках приватности claude.ai](https://claude.ai/settings/data-privacy-controls)
— проверьте его.

**Запасные поставщики**, если вы их подключили (OpenRouter, DeepSeek, NVIDIA, свой адрес): когда
у Claude кончился лимит, та же просьба с тем же контекстом уходит туда. Полностью локальный
режим — `justday model use ollama …`: тогда мозг работает на вашей видеокарте.

**Остальные сервисы — только если включены или нужны для просьбы:**

| Сервис | Когда | Что уходит |
|---|---|---|
| ElevenLabs | озвучка `tts.engine = elevenlabs` | текст, который нужно произнести |
| YouTube (через yt-dlp) | «включи …», ссылки, расшифровка видео | поисковый запрос или ссылка |
| Open-Meteo | задан город для погоды | название города |
| OpenStreetMap (Nominatim, OSRM) | время в пути до встречи, `observer.travel` | текст места из события, две точки маршрута |
| Telegram | вы подключили бота | переписка с ботом и, если вы её транслируете, геопозиция |
| Telnyx | звонки и SMS, если подключены | номер и сказанное в трубку |
| Ваш почтовый сервер и календарь | подключены почта или календарь | вход по паролю приложения / ссылке iCal |
| GitHub | проверка обновлений раз в 6 часов | обычный `git fetch`, ничего о вас |

Каждый из этих сервисов обрабатывает данные по своим правилам; JustDay их не контролирует.
Рекламы, счётчиков посещений и сторонней аналитики в JustDay нет. Телеметрия Claude Code
выключена в `brain/settings.json`.

## 3. Как удалить свои данные

Все данные JustDay — ваши файлы, и удалить их можете вы сами, без запроса к автору:

- **Всё сразу:** `./uninstall.sh --purge` в папке программы — удаляет программу, настройки, кэш обложек и видео,
  память, журналы, модели, отпечаток голоса и все ключи JustDay из связки ключей.
- **По частям:** буфер обмена — «Забыть всё» в панели или `justday clip wipe`; заметки памяти — в
  настройках, раздел «Память», или `justday memory forget ФАЙЛ`; разговор — `justday new-session`;
  чат — крестиком в списке чатов (вставленные картинки остаются в `chats/images/`, их удалить вручную); журнал — удалить файл `events.jsonl`.
- **То, что ушло в сторонние сервисы**, удаляется у них: переписка с Claude — в настройках
  claude.ai или запросом в Anthropic; у остальных — в их кабинетах.

## 4. Дети

JustDay не собирает данные о возрасте и никому их не передаёт. Чтобы пользоваться мозгом
ассистента, нужна учётная запись Anthropic, а у неё свои требования к возрасту — проверьте их в
условиях Anthropic. Если ассистентом пользуется ребёнок, учётные записи сервисов заводит и
настраивает взрослый.

## 5. Изменения

Политика меняется вместе с программой: новая редакция приходит с обновлением, история изменений —
в истории этого файла в репозитории.
