# Своя оболочка: один терминал

## Чего он хотел

Один терминал. Пишешь в него задачу — за неё берётся Claude Code. Кончился у него лимит, за ту же
задачу берётся следующий, и так вниз по лестнице: от лучшего к тому, что осталось. Не «открой
другое окно и расскажи всё заново», а то же окно и та же задача.

```sh
justday terminal                 # окно
justday terminal "почини док"    # одна задача строкой
```

## Как это сделано

Своего агента здесь нет и не будет. Claude Code и OpenCode — это уже готовые циклы с
инструментами, правами, сессиями и сжатием; переписывать их значит получить через месяц то же
самое, но хуже. Поэтому оболочка делает ровно то, чего не делает ни один из них по отдельности:

- **держит их лестницей.** Ступень пишется как `движок:модель`:
  `claude:opus`, `claude:sonnet`, `opencode:openai/gpt-6-sol`, `opencode:ollama/qwen3.5:9b`.
  Порядок в `terminal.ladder` — это и есть приоритет.
- **переносит задачу вниз с передачей.** Пришедший на смену получает задачу человека целиком, то
  немногое, что успел сказать предыдущий, и указание прочитать `ПЕРЕДАЧА.md`. «Продолжай» — это
  не начало: он не видел ничего из того, что было до него.
- **даёт сменить модель и усилие посреди работы** (`/model`, `/effort` → `--model`, `--effort`) и
  **попросить сжать разговор** (`/compact` уходит сообщением в ту же сессию). Это те четыре вещи,
  которых в самом Claude Code нет.

Сессия у каждой ступени своя и помнится: вернулись наверх — продолжили там, где остановились.

## Что в окне

```
› задача
  ответ бежит сюда, инструменты отмечаются точкой
  Claude Code · opus · ступень 1 из 5 · $0.1656
```

Команды: `/model`, `/effort`, `/compact`, `/ladder`, `/up`, `/new`, `/help`, `/quit`.

## Чего оболочка не делает нарочно

**Не уносит подписку Claude в чужие руки.** На верхней ступени запускается сама программа
`claude` — её сессия, её права, её же инструменты. Токен из неё мы не достаём и ни одному другому
клиенту не отдаём: с февраля 2026 Anthropic разрешает вход по подписке только своим программам.
Ступени ниже идут через OpenCode, где у человека свои ключи.

**Не ломится в ступень, куда нечем войти.** Такая ступень не отказывает — она висит молча и
бесконечно (проверено: три минуты без единого слова), и работа висит вместе с ней. Поэтому первого
слова ждём `terminal.first_word_seconds` (по умолчанию 90), а дальше сколько надо: думать десять
минут над настоящей задачей — нормально, и обрывать это по таймеру нельзя.

**Не спускается при обрыве связи.** Внизу тот же самый оборванный интернет, и спуск только
потеряет место в разговоре.

## Что рядом

- `justday work` — сесть в настоящий Claude Code, пока он отвечает; кончился лимит — открывается
  OpenCode. Это про «где работать руками», а не про «кто возьмёт задачу».
- `shell/opencode/` — лестница внутри самого OpenCode, для тех случаев, когда человек работает
  прямо в нём.
