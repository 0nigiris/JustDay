# Передача

Журнал для той модели, которая придёт следующей. Ведётся по ходу работы, а не в конце: конца может
не быть — лимит кончается посреди фразы. Прочитай целиком, прежде чем что-то делать.

Обновлено: 2 октября 2026, поздний вечер.

## Что это за проект

JustDay — личный ассистент для Linux (KDE Plasma 6, Wayland). Демон на Python (`src/justday/`) и
оболочка на QML/Quickshell (`island/`): Dynamic Island сверху, док, лоток, меню, Spotlight. Голос,
окна, музыка, почта, видео. Мозг — Claude Code через Agent SDK.

Хозяин проекта работает голосом и с телефона, пишет по-русски и ждёт ответа по-русски. Он не
программист: объяснять надо тем, что видно на экране, а не тем, как называется функция.

## Как здесь принято

Правила — в `docs/ПРАВИЛА.md` (общие, их читают обе оболочки) и `AGENTS.md` (этот проект).
Коротко: по-русски, комментарий объясняет **почему**, проверки до коммита, ключи только в связке
ключей, работать до конца и не спрашивать по пустякам.

Проверки:

```sh
ruff check .
.venv/bin/python -m pytest -q
/usr/lib64/qt6/bin/qmllint -I . island/ИМЯ.qml
bash -n install.sh
```

Выкладка (без неё человек изменений не увидит):

```sh
git push origin main
git -C ~/.local/share/justday/app pull -q --ff-only
systemctl --user restart justday justday-ui
```

## Что сделано за эту сессию

- **Конфигуратор.** `justday config set` искал секцию по строке ровно `[island]` и не узнавал
  заголовки с пояснением — дописывал вторую такую же секцию, и TOML переставал читаться целиком.
  Починено, закрыто тестами (`tests/test_config_set.py`).
- **Слияние PR #2 от Hikisey.** Взято его: размытие только под карточкой, Alt+Space, страница
  уведомлений, контур прилипания, палитра лотка, Meta+1..9. Возвращено наше, которое его ветка
  уносила: автосмена модели, три вида полосы, тихий режим, планы, живые сессии, стопки в доке.
- **Лестница поставщиков в демоне.** Вниз по лимиту, наверх по проверке (раз в N минут спрашиваем
  верхнего одним словом), крошечная местная модель для мелочей. `src/justday/fallback.py`,
  `_try_home`/`_pick_model` в `daemon.py`.
- **Оболочка.** OpenCode поставлен, к нему написан плагин-лестница
  (`shell/opencode/justday-ladder.js`), команда `justday shell` кладёт его на место, тянет ключи
  из связки в окружение и переносит в OpenCode все MCP и умения из Claude Code.
- **Вид.** Работа больше не молчит; музыка важнее работы; полоса прокрутки не вылезает из угла;
  панель инструментов больше не открывается пустой; док поспевает за быстрыми нажатиями.
- **Spotlight** переписан отдельной поверхностью (`island/SpotlightView.qml`) по спецификации
  человека, и починен порядок находок: «диск» теперь находит Discord первым, а не четыре файла.

- Трогать сервер **minevpsex** и плату **ESP32**.
- Писать ключи в файлы. Они лежат в связке ключей: `secret-tool lookup service justday key <имя>`.
- Сливать ветку Hikisey целиком: она собрана так, что уносит сделанное после неё. Разбирать
  по кускам, каждый кусок проверять.

  только там, где без него нельзя.
