# Оболочка: лестница нейросетей

Оболочка — это OpenCode: чёрное окно, в котором идёт разговор. Своего мы не писали, и писать не
стали: окно уже есть, и оно ровно такое, какое нужно. Наше здесь — **руль**: кто отвечает, когда
меняется и что делать, когда у него кончился лимит.

## Что он делает

Поставщики стоят лестницей. Наверху тот, кем хочется думать всегда, ниже — те, кем можно, пока
верхний молчит.

- **Вниз.** Отказ, похожий на лимит, спускает на ступень и говорит об этом строкой в окне.
  Обрыв связи не спускает: внизу тот же самый оборванный интернет.
- **Наверх.** Пока мы внизу, раз в четверть часа у верхнего спрашивают одним словом: «отвечаешь?»
  Ответил — поднимаемся. Спрашивают в отдельной сессии и только между делами: забрать работу у
  того, кто её делает, посередине — значит её потерять.
- **Мелочь — крошечной.** «Который час», «спасибо», «повтори» уходят маленькой местной модели.
  «Открой дискорд» короче, но это не мелочь: там надо не ответить, а сделать, а инструменты
  крошечной не даются.

## Как включить

```sh
npm install -g opencode-ai
mkdir -p ~/.config/opencode/plugin
ln -s "$PWD/shell/opencode/justday-ladder.js" ~/.config/opencode/plugin/justday-ladder.js
```

Настройка лежит рядом, в `~/.config/opencode/justday-ladder.json`:

```json
{
  "ladder": ["anthropic/claude-opus-4-5", "openrouter/deepseek/deepseek-chat", "ollama/qwen3:30b"],
  "tiny": "ollama/qwen3:0.6b",
  "probeMinutes": 15,
  "tinyMaxChars": 80,
  "quiet": false
}
```

`ladder` — порядок сверху вниз, `tiny` — крошечная модель (пусто — ступени нет), `probeMinutes` —
как часто спрашивать верхнего, `quiet` — не показывать строки о переходах.

## Чего он пока не делает

Сжатие контекста по своей воле. OpenCode умеет это сам (`/compact` и `agent.compaction`), а решать
за него, когда пора, — следующий шаг.
