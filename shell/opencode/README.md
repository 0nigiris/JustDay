# Оболочка: лестница нейросетей

Оболочка — это OpenCode: чёрное окно, в котором идёт разговор. Своего мы не писали, и писать не
стали: окно уже есть, и оно ровно такое, какое нужно. Наше здесь — **руль**: кто отвечает, когда
меняется и что делать, когда у него кончился лимит.

## Что он делает

Поставщики стоят лестницей. Наверху тот, кем хочется думать всегда, ниже — те, кем можно, пока
верхний молчит.

- **Вниз.** Отказ, похожий на лимит, спускает на ступень и говорит об этом строкой в окне.
  Обрыв связи не спускает: внизу тот же самый оборванный интернет.
- **Наверх.** Пока мы внизу, раз в четверть часа у верхнего спрашивают одним словом: «отвечаешь?»
  Ответил — поднимаемся. Спрашивают в отдельной сессии и только между делами: забрать работу у
  того, кто её делает, посередине — значит её потерять.
- **Мелочь — крошечной.** «Который час», «спасибо», «повтори» уходят маленькой местной модели.
  «Открой дискорд» короче, но это не мелочь: там надо не ответить, а сделать, а инструменты
  крошечной не даются.

## Как включить

```sh
npm install -g opencode-ai
justday shell
```

`justday shell` кладёт плагин на место, заводит ему настройку, если её ещё нет, и открывает окно.
Ключи он берёт из связки ключей рабочего стола и отдаёт окну переменными окружения: в настройках
OpenCode им не место — это обычный файл, который читается кем угодно и уезжает вместе с резервной
копией. Всё, что после `justday shell`, уходит самому OpenCode: `justday shell run "..."`.

Верхние ступени — подписка Claude: вход одной командой, по OAuth, без ключей в файлах.

```sh
opencode providers login      # выбрать anthropic
```

Настройка лежит рядом, в `~/.config/opencode/justday-ladder.json`:

```json
{
  "ladder": ["anthropic/claude-opus-5-5", "openrouter/deepseek/deepseek-chat", "ollama/qwen3:30b"],
  "tiny": "ollama/qwen3:0.6b",
  "probeMinutes": 15,
  "tinyMaxChars": 80,
  "quiet": false
}
```

`ladder` — порядок сверху вниз, `tiny` — крошечная модель (пусто — ступени нет), `probeMinutes` —
как часто спрашивать верхнего, `quiet` — не показывать строки о переходах.

Имена моделей при запуске подновляются по таблице переименований (`RENAMED` в
`src/justday/shell.py`): поставщик на прошлогоднее имя отвечает не «такой больше нет», а обычной
ошибкой, лестница считает её кончившимся лимитом и спускается — то есть один устаревший верх
молча уводит работу на самую слабую ступень. Остальное в настройке не трогается.

## Что ещё ставится вместе с ним

`justday shell` переносит в OpenCode весь инструмент Claude Code: умения из `~/.claude/skills` и из
каждого установленного плагина, MCP-серверы и правила (`docs/ПРАВИЛА.md` и `AGENTS.md` как
`instructions`). Там же включается автосжатие разговора (`compaction.auto`): длинная сессия без
сжатия кончается тем, что модель помнит начало и не помнит, что делала десять минут назад.

## Чего он пока не делает

Сам не решает, когда пора сжиматься: сжатие включено по порогу самого OpenCode, а не по тому,
что модель видит у себя впереди. Это следующий шаг.
